# Source and protocol provenance

The source boundary is the September 12 pre-revision snapshot, SHA256:

```text
ac8e4ea6cec6c51a34111b2459d26985cb4e8223ce7dbb8792266765486b8475
```

[source_manifest.json](../provenance/source_manifest.json) records the 17 preserved legacy source members and their hashes. Their numerical code is copied byte for byte. The Gaussian model agrees with the August archive; the retained trainer includes the August 28 FP32 logit-ranking correction. This establishes the preserved release source, not an exact source commit used at the time of every historical paper run.

[config_manifest.json](../provenance/config_manifest.json) binds the 45 archived configurations to the path-normalized release copies. Only data paths, run-root paths and related portability references change. The model, losses, optimizer recipe, loader settings, validation selection and early stopping remain the archived values. [preprocessing_manifest.json](../provenance/preprocessing_manifest.json) similarly records the separately preserved feature utilities. New package entry points add path resolution, strict validation, completed-run protection, checkpoint identity checks and evidence reporting outside the immutable model/trainer source.

The optional Python constructor `SAGFDTI(config)` accepts the complete archived configuration. Calling `SAGFDTI()` without a configuration inherits the frozen implementation's generic defaults, which differ from the conditioned paper model. Use a shipped paper configuration for its model shape and checkpoint compatibility. The train, evaluate and benchmark commands always supply the complete configuration.

[archived_prediction_audit.json](../provenance/archived_prediction_audit.json) binds all 45 historical prediction CSVs, metric JSONs and configuration YAMLs by SHA256, and records every seed plus nine five-seed groups. Recomputed AUROC, AUPR and six threshold classification metrics match the saved metadata exactly. Both population and sample SD are recorded; the reported SNAP cold-protein spread matches sample SD.

Source inspection establishes a score-column version boundary. The August 27 trainer computes `sigmoid(logit1 - logit0)`, ranks those probabilities, and exports `logit1` alone as `pred_logit`. The August 28 correction, retained in this release, first converts both class logits to float32 and then ranks their difference; its `pred_logit` column exports that binary margin. The audit records source archive/member hashes for both versions. Re-ranking the old positive-class column changes all 45 AUROC/AUPR pairs, but uses a different score and is not corrected-ranking reproduction. Exact corrected margins cannot be reconstructed from these CSVs because `logit0` is absent and stored probabilities are rounded, sometimes saturated. The artifact audit establishes no fresh training result.

The release excludes original workspaces, unrelated research history, raw datasets, cached features, pretrained weights, saved checkpoints, archives and credentials. The copied code is the upload payload; input and run artifact locations remain user supplied.
