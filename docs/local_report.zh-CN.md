# 本次整理与本地验证说明

本次发布整理的是论文对应的 SAGF-DTI 高斯融合代码。原模型和训练器从修订前备份中完整保留；新的入口负责路径配置、检查数据和保存实验记录。

## 已经验证的内容

- 原模型的 17 个源码文件与备份逐字节一致，完整保留 KPGT、ESM2、ESMDance 条件化动态分支、高斯融合及原来的损失函数。
- 从独立的干净 Git 克隆运行，109 项测试全部通过。训练、保存模型、重新加载模型和评估可以完整执行。
- 12 GiB RTX 5070 能运行原来的训练 batch32 和评估 batch64。选取的蛋白都达到 1500 个残基，峰值显存约 6.16 GiB。
- 本机 WSL 的锁页内存分配存在限制，因此使用显式的 `--disable-host-pinning`。这项调整记录在实验文件中；模型、batch、损失函数和混合精度设置保持原配置。

## 已完成的正式复现

SNAP 官方冷蛋白划分的五种子从头训练已 **5/5 完成**。2026 年 10 月 11 日北京时间约 02:10 开始，约 05:17 全部完成；每次最多 50 个 epoch，验证集连续 8 个 epoch 不改善时早停。只依据验证集 AUROC 选取模型，选定后才评估测试集，再独立重新加载 checkpoint 核对。

本次得到了与论文相近水平的结果。历史结果按保存的概率排名，本次按发布训练器的 FP32 二分类 logit 差值排名，且硬件与 WSL pinning 设置存在明确差异；因此不能将得分差异解释为模型改进，也不能声称数值完全复现。原论文主实验 checkpoint 未保留；本次证据来自五次新的完整训练。其余八组仅做了历史预测审计，未重新训练。
