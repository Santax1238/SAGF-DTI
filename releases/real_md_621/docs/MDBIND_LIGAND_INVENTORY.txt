================================================================================
DATA STORAGE IN .PT FILES
================================================================================

Each processed .pt file contains:

{
  'graph': torch_geometric.data.Data
    ├── x: [num_residues, 5]              # Node features
    │   ├── [0] RMSF (flexibility)
    │   ├── [1] SASA mean
    │   ├── [2] SASA std
    │   ├── [3] pocket_flag (ligand-contact indicator)
    │   └── [4] ligand_contact_freq
    ├── edge_index: [2, num_edges]        # Sparse residue graph edges
    └── edge_attr: [num_edges, 5]         # Edge features
        ├── [0] static_contact
        ├── [1] dynamic_contact_occupancy
        ├── [2] dccm (cross-correlation)
        ├── [3] ca_dist_mean
        └── [4] ca_dist_std

  'residue_names': List[str]              # 3-letter AA codes (e.g., 'ALA', 'GLY')
  'residue_numbers': List[int]            # PDB residue numbers
  'chain_ids': List[str]                  # Chain IDs ('A', 'B', etc.)

  'ligand_residue_names': List[str]       # ← LIGAND INFO: PDB codes (e.g., ['GDP'])
  'ion_residue_names': List[str]          # Metal ions present

  'node_feature_names': List[str]
  'edge_feature_names': List[str]
  'temporal_slices': List[Dict]           # Per-replicate snapshots (10 replicates)
  'dense_pair_features': Dict             # Dense pairwise statistics

  'metadata': Dict
    ├── local_id
    ├── num_protein_residues
    ├── num_ligand_residues              # Count of ligand residues
    ├── num_frames (total MD frames)
    ├── contact_cutoff_nm (0.8 for protein-protein)
    ├── ligand_contact_cutoff_nm (0.45)
    └── source_replicates: List[Dict]    # PDB/XTC filenames
}

================================================================================
ACCESSING LIGAND INFORMATION IN CODE
================================================================================

import torch

# Load one complex
data = torch.load('data/mdbind_processed/A004B.pt', map_location='cpu', weights_only=False)

# Get ligand name(s)
ligands = data['ligand_residue_names']  # e.g., ['GDP']
print(f"Bound ligands: {ligands}")

# Get binding pocket residues (which residues contact the ligand)
x = data['graph'].x
pocket_flag = x[:, 3]  # 4th feature is pocket_flag
contact_freq = x[:, 4] # 5th feature is ligand_contact_freq

# Identify binding pocket
pocket_residues = [
    data['residue_names'][i]
    for i in range(len(data['residue_names']))
    if pocket_flag[i] > 0
]
print(f"Binding pocket: {len(pocket_residues)} residues")

# Per-residue contact frequency with ligand
for i, residue_name in enumerate(data['residue_names']):
    if contact_freq[i] > 0:
        print(f"  {residue_name}{data['residue_numbers'][i]}: "
              f"contacts ligand {contact_freq[i]:.1%} of frames")

================================================================================
IMPORTANT LIMITATIONS
================================================================================

1. NO SMILES or Molecular Graphs
   - Cannot generate ligand embeddings directly
   - Cannot perform ligand-ligand similarity
   - Ligand info is NAMES ONLY (PDB 3-letter codes)

2. NO Per-Frame Ligand Poses
   - Only aggregate contact frequencies stored
   - No frame-by-frame binding information

3. NO Chemical Properties
   - No molecular weight, logP, etc.
   - No functional group information

4. NO Binding Affinity Labels
   - This is MD trajectory data
   - No experimental Ki/Kd values included

5. For DTI Prediction:
   - Would need to source ligand structures separately
   - Can extract from original PDB files using ligand codes
   - Then generate features with RDKit or similar

================================================================================
HOW TO EXTRACT ACTUAL LIGAND STRUCTURES
================================================================================

Since .pt files only have ligand names, you can:

1. Get PDB code from A004B → Ligand name 'GDP'
2. Extract from raw PDB files:
   - Open mdbind_50_locals/A004B/A004B.1_structure.pdb
   - Find all atoms with residue name 'GDP'
   - Extract HETATM records
3. Use RDKit to parse/generate SMILES:
   - pip install rdkit
   - mol = AllChem.MolFromPDBFile(...)
   - smiles = Chem.MolToSmiles(mol)

Or use PDB Chemical Component Dictionary:
   - https://www.rcsb.org/dict/
   - Query 'GDP' → returns SMILES and 3D structure
